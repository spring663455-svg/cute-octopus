# 小章魚算算樂

一個適合兒童使用的加減法練習網頁，提供加法、減法與混合題型，以及 10、20、100 以內的數字範圍。

## 桌面上一鍵啟動

不需要輸入指令，下載並解壓縮整個專案資料夾後：

- **Windows**：雙擊 `啟動小章魚.bat`。
- **macOS**：雙擊 `啟動小章魚.command`。第一次開啟若被阻擋，請按住 Control 點擊檔案，再選擇「打開」。
- **Linux**：允許 `啟動小章魚.command` 作為程式執行後，再雙擊開啟。

啟動器會自動尋找可用連接埠並打開瀏覽器。關閉啟動器的終端機視窗即可停止程式。電腦需已安裝 Python 3。

## 使用指令啟動

直接以瀏覽器開啟 `index.html`，或在專案目錄啟動靜態伺服器：

```bash
python3 -m http.server 8000
```

接著開啟 <http://localhost:8000>。
